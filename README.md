#### 🔒 [DMATRIX — Offline, Hardware-Aware Agentic AI Platform](https://github.com/gokulcodes10/DMATRIX-case-study)

Teams in air-gapped or GPU-constrained environments can't use cloud LLMs. DMATRIX profiles the host hardware, classifies its runtime tier, auto-selects models that actually fit, and serves private chat with live telemetry entirely on-prem — from 72B AWQ models on GPU down to CPU-only GGUF.

#### 🔒 [MET — Model Evaluation & Trust](https://github.com/gokulcodes10/met-case-study)

LLM leaderboards report false-precision point ranks. MET ships every score with a confidence interval and publishes rank *sets* — clustered bootstrap CIs, paired permutation tests, and a tamper-evident git-as-ledger provenance trail — all on a $0 infrastructure budget.

![Python](https://img.shields.io/badge/-Python-05122A?style=flat&logo=python&logoColor=white) ![React](https://img.shields.io/badge/-React-05122A?style=flat&logo=react&logoColor=white) ![GitHub Actions](https://img.shields.io/badge/-GitHub%20Actions-05122A?style=flat&logo=githubactions&logoColor=white)

🔒 **Private repo** — architecture & demo available in the [case study](https://github.com/gokulcodes10/met-case-study).

#### 🔒 [HESMA — High-Entropy Alloy Feature Calculator](https://github.com/gokulcodes10/HESMA-scientific-tool-case-study)

Materials researchers need fast thermodynamic screening of high-entropy shape-memory alloys. Interactive periodic table in → phase, stability, and mechanical property predictions out, with PDF/Excel export. Built with guidance from DRDO lab researchers.
